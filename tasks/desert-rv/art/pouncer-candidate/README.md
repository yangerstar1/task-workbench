# Original pouncer art candidate v001

UNREVIEWED. Standalone art experiment; does not change RV, Unity scenes, import manifests or gameplay. No private reference image, external mesh, downloaded animation or third-party texture is included. All sculpt input, topology union, pigment colors, skeleton and clips are generated by this source.

## Reproduce

Manually dispatch `Desert RV original pouncer candidate` as repository owner. The job downloads Blender 4.2.3 from Blender's official server and verifies its matching official checksum before execution. No Blender or Unity run is required on the user's machine or dot computer. Generated asset output depends on the pinned Blender version and seed; byte-identical blend metadata is not promised.

Outputs: clean blend, GLB, FBX, parameters, seven-clip manifest, technical validation JSON, source commit, official Blender checksum, eight neutral-lit view PNGs, motion side views, MP4s, contact sheets and SHA256SUMS. Review stage is a separate blend. GLB embeds vertex-color sandstone material; FBX carries vertex colors but a compatible vertex-color shader is required in Unity. No texture-map parity is claimed.

## Shape and integration

Low, heavy forequarters; broad short wedge head; no wolf ears or long canine muzzle; tucked belly; short stiff tapering tail; fused dorsal ridges; dark ventral countershade and restrained sandstone sediment bands. One voxel-unioned continuous deforming skin. Detail meshes only for eyes, mouth seam and claws. 43-bone rig and normalized maximum-four weights. Total mesh triangle hard gate 8–12k. Dimensions in meters. Blender Z-up / -Y-facing is exported glTF Y-up and FBX Y-up / -Z-forward.

Seven named actions: Idle, Walk, Windup, Attack, Recover, Hit, Death. Requested seconds are in parameters; sampled durations are recorded because 30 fps rounds subframes. Root motion is disabled. Walk interface speed is 2.7 m/s; actual gait synchronization requires engine review. Attack is a true visual-body leap and bite, with stationary gameplay root, followed by landing. A non-deforming visual_body bone owns transient forward displacement and height. Recover starts grounded; the runtime contract is an at-most 0.18-second transition to Recover. Three synthetic interrupt clips (25%, 50%, 75% of Attack) are rendered separately and measure landing contact after the transition. They do not prove Unity controller behavior: runtime interruption must still be tested before adoption. Death is a full side-lying collapse with a stable final hold, not a head-down gesture.

## Known unfinished art work

This is a first inspectable candidate, not production approval. It needs eight-view silhouette/material review, shoulder/hip deformation review, foot locking and contact refinement, death-ground contact review, final bite timing and original sound design. Distance-based weights are deterministic starting weights, not hand-painted final anatomy. A technical green result does not approve the creature's appearance or animations. Never automatically insert this output into a production scene.
